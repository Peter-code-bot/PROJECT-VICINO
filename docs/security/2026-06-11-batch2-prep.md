### #8 -- DETALLE (schema + flujo + maquina de estados)

**CREATE TABLE** (`20260412000001_appointments.sql:8-20`):
```
CREATE TABLE appointments (
  id UUID PK DEFAULT gen_random_uuid(),
  product_id UUID NOT NULL REFERENCES products_services(id) ON DELETE CASCADE,
  buyer_id  UUID NOT NULL REFERENCES profiles(id),
  seller_id UUID NOT NULL REFERENCES profiles(id),
  appointment_date  DATE NOT NULL,
  appointment_start TIME NOT NULL,
  appointment_end   TIME NOT NULL,
  status TEXT DEFAULT 'confirmed' CHECK (status IN ('confirmed','cancelled','completed')),
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (product_id, appointment_date, appointment_start)
);
-- + 20260424000001: reminder_1d_sent BOOL NOT NULL DEFAULT false, reminder_1h_sent BOOL NOT NULL DEFAULT false
```
**Estado:** NO es enum -- es `TEXT` con CHECK. Valores: `confirmed` (default), `cancelled`,
`completed`. La cita NACE `confirmed` (no hay paso de "pendiente" / confirmacion del vendedor).
Campos de agenda en products_services: `allow_appointments BOOL`, `appointment_start_time TIME`,
`appointment_end_time TIME`, `appointment_duration_minutes INT`.

**Policies actuales** (`20260412000001:24-26`, wrapped en `20260602000001:495-501` con
`(select auth.uid())` + `TO authenticated`):

- INSERT `"Authenticated users can create"` -- `WITH CHECK (auth.uid() = buyer_id)`  [no valida seller_id ni allow_appointments]
- UPDATE `"Participants can update"` -- `USING (auth.uid() = buyer_id OR auth.uid() = seller_id)`  [sin WITH CHECK -> cambia CUALQUIER columna]

**Triggers:** solo `push_on_appointment_pgnet` AFTER INSERT -> `call_send_push_on_appointment()`
(Vault, `20260604000005` / `20260610000007`). NO hay trigger updated_at (la tabla solo tiene
created_at). Indices: `idx_appointments_product_date`, `idx_appointments_buyer`,
`idx_appointments_seller_id` (A2), `idx_appointments_reminder_pending`.
